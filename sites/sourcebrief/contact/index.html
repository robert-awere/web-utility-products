Contact

Help improve SourceBrief.

The easiest way to report a problem, suggest an improvement, or ask a privacy question is through the public SourceBrief issue tracker.

Best contact route

Open a GitHub issue in the SourceBrief project repository. Please include the repo you scanned, what you expected to happen, what happened instead, and the SourceBrief URL if the issue relates to a specific result page.

Open a SourceBrief issue

Before you send anything

  • Do not include passwords, tokens, secrets, private repo names, or confidential data.
  • GitHub issues are public unless the repository owner handles them another way.
  • If your concern is privacy-related, say so clearly at the top of the issue.
  • If you are reporting a confusing repo brief, include the exact public repo name.

Useful feedback examples

Good reports include concrete details: a repo that produced a weak summary, a misleading safety signal, a broken related-repo suggestion, a mobile layout problem, or a missing explanation that would help new visitors.

SourceBrief does not collect contact details through this page. If you choose to use GitHub, your interaction is handled by GitHub.
