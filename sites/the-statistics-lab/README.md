# The Statistics Lab

Production snapshot of [thestatisticslab.io](https://thestatisticslab.io/), archived from the live Hostinger AI Builder deployment.

## Run locally

```sh
python3 -m http.server 8000
```

Open <http://localhost:8000/>.

This is the compiled static bundle available from the deployed site. The editable Hostinger project/source is not exposed by the public deployment.
