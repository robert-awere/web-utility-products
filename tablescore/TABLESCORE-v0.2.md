## Known limitations / residual risks

- One game only. No Canasta or other roster pages.
- Partnership play is one named column per side, not two linked seats.
- The keeper does not validate wild-card limits inside a meld, initial-meld legality, or partner permission.
- Card-point entry is by count of ranks, not by tapping individual cards.
- Cold open with no network still needs a first load (or a previously filled SW cache). After first load, scoring does not call a server.
- Sitemap loc values are paths, not absolute URLs — no domain was chosen.
- Contact page has no form.
- Ad slots are empty boxes.
- robots.txt disallows crawlers; this is a sandbox.
- Saskatchewan / Simpson play-rule differences (discard-pile size, 11-card hand, adding past seven) are not simulated. Only published scoring differences are toggled.
- lighthouse is a devDependency so the section 13.5 run can be repeated; it is not needed to score a game.
- window.__TABLESCORE is a test hook on the game page (engine functions only).
